# 读懂宪法 · 法治在身边（画面优化版）

直接打开 index.html 即可查看。所有画面、视频与原有音乐均在 assets 内，无构建步骤。

## 本次调整

- 首页背景改为原素材“国旗与广场晨光”，避开原书封文字与标题重叠；大标题左对齐，国旗为画面主体。
- 8 屏统一朱红、深红与柔金体系，增强标题、正文与图像的层次；内页按照片与插画构图分别裁切。
- 文字按类型加入场特效：首页标题逐字浮现、开篇横向揭幕、介绍与案例标题由虚到实、引文展开、四项要点依次浮入、结语逐字柔金高光；正文轻缓上浮。
- 特效由文字实际进入视窗时触发，长页面也可逐段显示；整屏离开后再返回会重播，支持系统“减少动态效果”。
- 长文可随页面自然滚动，小屏不再依赖卡片内滚动；保留沉浸式纵向滑动体验。
- 视频封面改为实际视频画面，视频播放时暂停背景音乐，暂停/结束后按用户此前选择恢复；音乐按钮始终可操作。
- 案例页压缩措辞，并增加“相关批复已于2008年废止”的历史注，链接原新闻资料。未进行全文法律审校。

## 背景音乐

打开“背景音乐推荐.html”查看 5 首曲目的试听/下载入口、适配建议和授权要求。“背景音乐推荐.md”为同内容的文字清单。

当前页面已采用 Cinematic Documentary Piano（SigmaMusicArt），文件为 assets/bgm_cinematic_documentary_piano.mp3，默认音量 24%。点击右上角按钮开始播放或暂停；视频播放时暂停，暂停、结束或离开视频后按用户原先开关状态恢复。原有氛围音仍保存在 assets/bgm_solemn_ambient.mp3 作为备份。曲目来源与授权见 MUSIC-CREDITS.md。

选择曲目后，将下载并获准使用的文件放进 assets，修改 index.html 中 audio#bgm 的 src，并按曲目要求添加署名。

## 本地预览

在此目录运行 `python3 -m http.server 8080`，浏览器访问 http://localhost:8080/；也可以直接双击 index.html。手机访问需部署到静态服务器。
